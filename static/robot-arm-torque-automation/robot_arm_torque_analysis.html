Use the sliders to adjust Claw / Limb1 / Limb2 length or mass. Mass is automatically linked in direct proportion to length (and vice versa), and each joint's static torque is updated in real time for the fully horizontal worst-case position.

Torque model (static, horizontal):
  • Payload COM assumed at 0.85× claw length
  • Claw structure COM at 0.50×
  • The 2 distal wrist servos (grip + spread) COM at 0.30×
  • Each limb is treated as a uniform beam with COM at 0.50×
These ratios can be adjusted easily in the code if needed.

Usage notes
  • The elbow is often the first joint to become limiting. If the torque bar moves into yellow or red, reduce length/mass or lighten the structure.
  • This is a static horizontal worst-case estimate. Real acceleration, shock, friction, and mechanism losses require more margin, especially at the elbow.
  • The shoulder model assumes the 2 motors share load equally. In practice, frame stiffness and mechanism mismatch can change load sharing.
